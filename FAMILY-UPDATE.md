# Семейная цель, задания и справка

## Установка

1. Сделайте копию Google Таблицы через «Файл → Создать копию».
2. В существующем проекте Apps Script замените содержимое Adventure.gs.
   Это файл скрипта, НЕ Adventure.html. Code.gs оставьте без изменений.
3. Сохраните и обновите существующее развертывание: «Развернуть → Управление
   развертываниями → карандаш → Новая версия → Развернуть».
   Адрес существующего развертывания /exec не меняется.
4. В корне GitHub-репозитория замените: index.html, adventure.js, game.css,
   hero-art.js, demo.js, sw.js. config.js НЕ меняйте.
5. После публикации GitHub Pages откройте игру. Первый запрос автоматически
   создаст три новых листа, сохранив прежние данные. Закройте и снова откройте
   игру, если установленное приложение показывает старую версию.

## Ежедневные задания: daily_tasks

Каждая строка относится к одному участнику:

| Столбец | Значение |
| --- | --- |
| char | a = Ангелина, s = Светлана, m = мама, p = папа |
| task_id | Постоянный ID. У существующих заданий НЕ менять |
| name | Название, можно менять |
| xp | Награда от 1 до 100; столько же личных монет |
| active | TRUE = показывать, FALSE = выключить |
| weekdays | Пусто = каждый день; иначе номера через запятую: 1,3,5. Пн = 1, вс = 7 |

Для нового задания добавьте строку, оставив task_id пустым: игра заполнит
его сама. Для изменения формулировки меняйте только name, а не ID.
Для отключения поставьте FALSE, не удаляя историю. Не копируйте ID другого
задания того же участника. Если день недели уже стал числом или датой,
задайте столбцу weekdays формат «Обычный текст» перед вводом списка.

После редактирования нажмите обновление в игре. Сохранение таблицы происходит
автоматически. GitHub для смены ежедневных заданий больше не нужен.

## Семейная цель: family_goals

Начальная строка создана как черновик, а не обещанная детям поездка.

| Столбец | Значение |
| --- | --- |
| goal_id | Постоянный ID этой цели; не менять при переименовании |
| name | Например, «Наша поїздка у Phantasialand» |
| target_steps | Сколько нужно шагов, например 120 |
| start_date | Дата начала в формате 2026-10-18 |
| status | draft = черновик; active = активна; achieved = достигнута; archived = архив |
| image_url | Необязательная прямая HTTPS-ссылка на общедоступную картинку |

Выберите название, количество шагов, дату начала и поставьте active.
Держите активной только одну цель: при нескольких используется первая
начавшаяся строка. Пустая картинка допустима, цель работает и без нее.
Обычная ссылка на страницу Google Drive не является прямой ссылкой на картинку.

Первые три подтвержденных дела каждого участника за день дают по одному
семейному шагу. Монеты не списываются. Вклад виден в постоянном порядке,
без рейтинга. Старые задания не начисляются задним числом. После достижения
порога новые шаги для этой цели не начисляются; личные награды продолжаются.
Дата поездки выбирается родителями отдельно. В поездке участвуют все.

Шаги сохраняются в журнале с ID цели, не обнуляются в понедельник и не
переносятся в другую цель. Не увеличивайте порог уже обещанной цели без
обсуждения с детьми. Для новой поездки старую строку пометьте archived,
добавьте новую с пустым goal_id и поставьте active.

## Вопросы: game_help

question = вопрос, answer = ответ, active = TRUE/FALSE.
Можно добавлять строки, менять формулировки и порядок. Текст отображается
как обычный текст, без HTML. Раздел открывается кнопкой «?» возле настроек.
При изменении правил следите, чтобы ответы оставались им верны.

## Личные цели: goals

Существующий лист и правила одноразовой награды сохранены. Завершение теперь
выделяется в интерфейсе, а цель с датой остается в «Мій шлях → Мої досягнення».
Для исправления названия не меняйте goal_id. Для действительно новой цели
измените название/награду и очистите goal_id: игра создаст новый.
Пошаговые подцели в эту первую версию не добавлены.

## Что не изменялось

Ни один прежний лист не удален. Очистка и реорганизация существующей таблицы
требуют ее актуального файла. Не удаляйте листы adventure_events,
adventure_opening, data, quests и другие старые листы по внешнему виду:
они могут использоваться для истории или совместимости.

В эту версию перенесены именно ежедневные задания, семейные цели и справка.
Каталог графических образов и названия наград за уровни пока остаются в коде.
У четырех героев разные детали внешности; роли, одежда и открытое
спорядяжение сохранены. Выбор темы и быстрое сохранение также сохранены.

## Проверка после установки

Измените название одного задания в daily_tasks, нажмите обновление в игре.
Задание должно переименоваться без повторного начисления награды.
Активируйте семейную цель, отметьте действительно выполненное дело и
дождитесь подтверждения. Вклад должен увеличиться на один (если дневной
предел еще не достигнут). Откройте «?» и прочитайте правила вместе с детьми.

Локально проверены правила начислений, повторные запросы, ограничения шагов,
изменение заданий, справка, четыре образа и мобильная/настольная верстка.
Продуктивная таблица и опубликованный сайт автоматически не изменялись.
